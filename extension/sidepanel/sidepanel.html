Riff

Connect your inspiration repo

Riff saves every idea to a GitHub repo you own, so your coding agents can read it.

  1. Create an empty repo, for example inspiration.
  2. Create a fine-grained token for that repo only, with Contents: Read and write.

Stored only in this browser. Riff sends it to api.github.com and nowhere else.
